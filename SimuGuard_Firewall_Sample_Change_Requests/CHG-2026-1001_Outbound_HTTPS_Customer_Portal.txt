CHANGE REQUEST: CHG-2026-1001

Short Description: Allow outbound HTTPS connectivity for Customer Portal API

Requested By: Rahul Sharma
Assignment Group: Network Security Operations
Change Type: Normal
Priority: Medium
Category: Network Security
Subcategory: Firewall Rule Modification

Business Service: Customer Web Portal
Application: APP-001-CUSTOMER-PORTAL
Environment: Production

Target Firewall: PAN-NGFW-EDGE-01
Firewall Platform: Palo Alto PA-5450
Management Platform: Panorama

Change Operation: Create Security Policy

Rule Name: Allow-Customer-Portal-API-HTTPS
Source Zone: Trust-Application
Destination Zone: Untrust-Internet
Source Address: 10.100.10.0/24
Destination Address: 198.51.100.25/32
Application: ssl
Service: tcp-443
Protocol: TCP
Destination Port: 443
Action: Allow
Security Profile Group: Strict-Enterprise-Security
Logging: Enabled at session end

Business Justification:
The Customer Portal API requires outbound HTTPS connectivity to an external payment gateway for payment transaction processing. The current firewall policy blocks this communication.

Implementation Plan:
1. Create the proposed security policy in Panorama.
2. Restrict the source to 10.100.10.0/24.
3. Restrict the destination to 198.51.100.25/32.
4. Allow only HTTPS application traffic.
5. Enable security profiles and logging.
6. Validate policy configuration before deployment.

Validation Plan:
Perform a connectivity test from the application subnet to the payment gateway on TCP port 443. Verify firewall traffic logs.

Backout Plan:
Disable the newly created security policy and restore the previous configuration.

Expected Impact:
No service downtime expected. Only the specified application traffic should be affected.

Requested Maintenance Window:
16 November 2026, 22:00–23:00 IST

Risk Assessment Requested:
Please evaluate policy scope, destination exposure, application dependencies, security profiles and potential blast radius before CAB approval.
